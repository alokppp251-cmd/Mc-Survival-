## Features

This project repo has the following:

- Configurable random mouse movements with adjustable speed and interval settings.
- Safe-zone margins to keep the cursor away from screen edges and corners.
- Simulated keystrokes (e.g., Shift, Ctrl) at user-defined intervals to prevent idling.
- Console logging of each move count and coordinate for real-time monitoring.
- Graceful shutdown on Ctrl+C with a friendly exit message.
- Robust exception handling that reports errors without crashing the bot.
- Built-in support for easing/tweening functions to create natural, human-like mouse paths.
- Modular code structure so you can easily swap in new actions (different keys, click patterns, etc.).
